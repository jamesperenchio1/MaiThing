# QoL Pack 2 — Discovery, Chat, Flash Sales & Rich Analytics

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship a second wave of quality-of-life upgrades covering smart discovery for 100+ stores, auto-chat on order placement, per-listing flash sales, and a full merchant analytics expansion.

**Architecture:** All features stay within the existing mock-repository pattern. Types are extended in `src/types/index.ts`, interfaces in `src/repositories/interfaces.ts`, data in `src/repositories/seed.ts` and `mock.ts`, and screens are modified in-place with no new route files.

**Tech Stack:** Expo SDK 57, React Native 0.86, NativeWind 4, TanStack Query 5, Zustand 5, lucide-react-native, expo-router 4.

## Global Constraints

- TypeScript strict mode — no `any`, no unused imports, no type assertions unless unavoidable.
- NativeWind/Tailwind classes only — no inline `style={{}}` unless platform-specific.
- Colors: use `colors.primary` / `colors.muted` etc. from `useThemeColor()`, never hard-coded hex.
- Hex literals for the two brand greens (`#16A34A` / `#4ADE80`) are allowed in Tailwind config only.
- All mock data calls are fire-and-forget where they're side-effects; never block the UI.
- After each task: run `pnpm typecheck` and `pnpm lint` — both must pass before committing.
- Commit message format: `feat(scope): description`.

const handleStartFlashSale = async () => {
